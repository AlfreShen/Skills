# eli5

給人讀的說明。模型照 `SKILL.md` 做事，不讀這份。

## 使用場景

- 使用者明確點名 eli5（打 eli5 或 `/eli5`，任何語言都算），要把一個主題講給完全不懂的人
- 沒點名 eli5 的「解釋一下」「簡單說」不會觸發，照一般對話回答

## 功能

- 做成一頁自足的 HTML：圖負責解釋，字只當標籤
- 假設讀者完全沒有背景知識，但不假設讀者笨；拿掉術語與前置知識，不拿掉內容，不用哄小孩的口吻
- 圖用內嵌 SVG 或 CSS 畫，不載入外部圖片，不拿 emoji 當圖
- 類比只用在它成立的範圍內
- 每張圖一行字以內；需要一段文字時改圖，不加字
- 一個畫面一個概念；預設直向捲動、大字、留白多，整頁一分鐘內讀完
- 主題壓縮不了時，交出頁面後簡短說明，不硬做過度簡化的版本

## 不處理的事

- 一般的解釋、摘要、拆解要求：直接在對話裡回答
- 投影片：`slides`
- 架構圖、資料流程圖：`arch-diagram`

## 需要的工具

- 能建立 HTML artifact，或能寫出一個 HTML 檔讓使用者用瀏覽器打開

## 專案自訂的事項

- 讀者是誰、頁面用什麼語言、配色與字型、閱讀時間的目標、頁面存放或發布的位置，寫在該專案自己的指示（`CLAUDE.md`、Project instructions），不寫進這份 skill
